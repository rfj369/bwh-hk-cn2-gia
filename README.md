## 为什么这么贵：CN2 GIA 到底是什么线路

贵的原因一句话能说完：回程三网都走电信 CN2 GIA，这是中国电信等级最高的国际线路。

电信的回内地线路分三档。最常见的是 ChinaNet 163 骨干网（AS4134），晚高峰拥堵严重，丢包率在晚间能超过 30%；中间档是 CN2 GT，价格更高，但近几年也开始拥堵；最顶层是 CN2 GIA（AS4809），专线级别，晚高峰抗拥堵能力远超前两档。搬瓦工香港走的是第三档，这在第三方测评里得到过反复验证：有博主用 NextTrace 从北京、上海、广州、成都对三大运营商做回程路由追踪，结果全部落在 AS4809 上。

具体到延迟数字（2026 年 5 月的实测）：

- 广州电信回程约 7.6ms，广东方向整体低至 9ms 上下
- 上海电信约 27ms，华南华东普遍在 30ms 左右
- 全国 80 多个探针节点平均 46.2ms，其中联通平均 38.7ms 表现最好，电信 46.6ms，移动 57.0ms

丢包方面，绝大多数探针 0% 丢包，联通方向基本零丢包；移动方向有少数节点（华北、华南）出现超时甚至 100% 丢包的情况。如果你的用户主要走移动网络，下单前最好先拿测试 IP 在自己网络环境跑一遍。

磁盘性能也顺手看一下：4K 随机读写约 188 MB/s（IOPS 4.7 万上下），1M 顺序写 3.40 GB/s，bench.sh 三轮 I/O 平均 926 MB/s。对建站、数据库和 Docker 自托管来说，磁盘不会成为瓶颈。

流媒体解锁要单独提醒：这个机房的 IP 是广播 IP，能解锁 Netflix、Disney+、Spotify，但解锁不了 TikTok、ChatGPT、Claude 和 Gemini。冲着解锁 AI 服务去的读者，这台机器满足不了你。

**搬瓦工香港套餐是三网都走 CN2 GIA 吗？**
